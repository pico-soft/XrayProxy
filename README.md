# XrayProxy

**SOCKS5/HTTP прокси без VPN-интерфейса для Android**

[![Version](https://img.shields.io/badge/version-2.4--beta-blue)]()
[![License](https://img.shields.io/badge/license-MIT-green)]()
[![Platform](https://img.shields.io/badge/platform-Android%20(Termux)-brightgreen)]()

XrayProxy запускает [xray-core](https://github.com/XTLS/Xray-core) как локальный SOCKS5/HTTP-прокси в Termux. В отличие от VPN-клиентов, он **не создаёт VPN-интерфейс** (tun0) и **невидим** для приложений, которые проверяют наличие VPN через `ConnectivityManager.TRANSPORT_VPN`.

## Для чего

- Обход блокировок без VPN-интерфейса на устройстве
- Приложения (банки, маркетплейсы, доставка) не видят VPN
- Управление подписками VLESS+Reality из удобного интерфейса
- Автоматическое тестирование и выбор самого быстрого сервера
- Автомониторинг — при падении скорости автоматически переключает сервер
- CLI и Web-интерфейс (Flask) на выбор

## Установка

### 1. Установи Termux

Скачай из [F-Droid](https://f-droid.org/packages/com.termux/) (не из Google Play — там устаревшая версия).

### 2. Установи XrayProxy

Открой Termux и выполни:

```bash
apt update && apt full-upgrade -y
```

```bash
pkg install -y curl unzip
```

```bash
termux-setup-storage
```

> Появится диалог — нажми «Разрешить».

```bash
cd ~
rm -rf ~/xrayproxy ~/xrayproxy.zip
curl -fL --progress-bar --resolve github.com:443:140.82.121.3 -o xrayproxy.zip https://github.com/pico-soft/XrayProxy/releases/latest/download/xrayproxy.zip
unzip -o xrayproxy.zip
bash xrayproxy/install.sh
```

Установщик сам поставит Python, Flask, скачает xray-core и настроит всё.

#### Если curl зависает (GitHub заблокирован)

1. Открой в браузере: [Скачать xrayproxy.zip](https://github.com/pico-soft/XrayProxy/releases/latest/download/xrayproxy.zip)
2. Файл сохранится в Downloads (возможно как `xrayproxy (1).zip` — это нормально)
3. В Termux выполни:

```bash
apt update && apt full-upgrade -y
pkg install -y unzip python
termux-setup-storage
bash ~/xproxy/install.sh
```

Установщик автоматически найдёт последний скачанный `xrayproxy*.zip` в Downloads, распакует и установит.

Если это первая установка (файла `~/xproxy/install.sh` ещё нет):

```bash
cp ~/storage/downloads/xrayproxy*.zip ~/
cd ~
unzip -o xrayproxy.zip
bash xrayproxy/install.sh
```

### 3. Запусти

```bash
bash ~/xproxy.sh
```

Или веб-интерфейс:

```bash
bash ~/xproxy.sh web
```

Открой Firefox → `http://localhost:8080`

### 4. Добавь подписку

В CLI нажми `9`, в Web — поле внизу. Введи URL подписки — тот же, что используешь в v2rayNG, Happ или других клиентах.

### 5. Настрой приложения

| Приложение | Как настроить |
|-----------|--------------|
| **Telegram** | Настройки → Данные → Прокси → SOCKS5 → `127.0.0.1:10828` |
| **Firefox** | Установи FoxyProxy → SOCKS5 → `127.0.0.1:10828` + Proxy DNS |
| **WhatsApp, Instagram, ChatGPT** | Через Firefox: `web.whatsapp.com`, `instagram.com`, `chatgpt.com` |

Российские приложения (банки, СДЭК, Яндекс) работают напрямую — они не видят прокси.

## Автозапуск при загрузке телефона

Чтобы XrayProxy запускался автоматически при включении телефона:

### 1. Установи Termux:Boot

Скачай из [F-Droid](https://f-droid.org/packages/com.termux.boot/).

**Открой приложение Termux:Boot один раз** — просто запусти и закрой. Это активирует разрешение на автозапуск.

### 2. Настрой автозапуск

В Termux выполни:

```bash
bash ~/xproxy/setup-boot.sh
```

Проверь результат:

```bash
cat ~/.termux/boot/xrayproxy
```

### 3. Настрой Android

Чтобы Android не убивал Termux в фоне:

- **Настройки → Приложения → Termux → Батарея → Без ограничений**
- **Настройки → Приложения → Termux:Boot → Батарея → Без ограничений**
- На Samsung дополнительно: Настройки → Обслуживание устройства → Батарея → убрать Termux из ограничений

### 4. Перезагрузи телефон

Подожди 20–30 секунд после загрузки, затем открой Firefox → `http://localhost:8080`.

Проверить, что автозапуск сработал:

```bash
cat ~/xproxy/boot.log
```

## Возможности

- **Автоподключение** — находит и подключает самый быстрый сервер
- **Автомониторинг** — каждые 2 минуты замеряет прямую скорость и скорость через туннель. Если прямой интернет слабый — не переключает (экономит ресурсы). Если туннель медленнее 50% от прямой скорости — автоматически переключает сервер
- **Автопереключение при ручной проверке** — нажал «Проверить скорость», скорость ниже порога → автоматически переключает
- **3-этапное тестирование** — TCP-пинг → проверка прокси (2 сек) → замер скорости
- **Параллельный пинг** — 20 потоков, 100 серверов за 15 секунд
- **Фоновая проверка** — автоматически раз в час
- **Подписки** — импорт по URL, автоименование, раздельное управление
- **Стоп-лист** — фильтрация серверов по ключевым словам (РФ, Беларусь, Крым)
- **Fetch через прокси** — если URL подписки заблокирован, скачает через рабочий сервер
- **Веб-интерфейс** — управление из браузера на `localhost:8080` с автообновлением статуса
- **Автозапуск** — при перезагрузке телефона через Termux:Boot с проверкой соединения
- **Экспорт логов** — ZIP с диагностикой

## Обновление

### Через команду (рекомендуется)

```bash
bash ~/xproxy.sh update
```

Скрипт автоматически:
1. Попробует скачать напрямую с GitHub
2. Если заблокировано — скачает через работающий туннель XrayProxy
3. Если и это не удалось — найдёт ZIP в Downloads (скачай вручную через браузер)

Также доступно из Web-интерфейса: Настройки → кнопка «⬆ Обновить».

### Через браузер (если GitHub полностью заблокирован)

1. Скачай [xrayproxy.zip](https://github.com/pico-soft/XrayProxy/releases/latest/download/xrayproxy.zip) через браузер
2. В Termux:

```bash
bash ~/xproxy.sh update
```

Подписки, серверы, настройки и стоп-лист сохраняются — они хранятся в `~/xproxy/`, а `~/xrayproxy/` это временная папка установщика.

## FAQ

**Q: Приложения видят VPN?**
Нет. XrayProxy работает как обычный TCP-сервер на localhost. Никакого tun-интерфейса, никакого `TRANSPORT_VPN`.

**Q: Какие протоколы поддерживаются?**
VLESS (TCP, gRPC, WebSocket) с TLS и Reality.

**Q: Нужен ли root?**
Нет.

**Q: Почему не все серверы работают?**
XrayProxy проверяет серверы в 3 этапа. Те, что не прошли проверку прокси (этап 2), автоматически исключаются.

**Q: Как работает автомониторинг?**
Каждые 2 минуты (настраивается) скрипт замеряет скорость интернета напрямую (без туннеля). Если прямая скорость ниже порога (1 Мбит/с) — интернет слабый, переключение не происходит. Если прямая скорость нормальная — замеряет скорость через туннель. Если туннель медленнее 50% от прямой — переключает на следующий по скорости сервер и проверяет снова. Каскадно перебирает серверы и подписки.

**Q: Как обновить?**
См. раздел «Обновление» выше.

**Q: Как отправить логи для помощи?**
В CLI: пункт `x`. В Web: Настройки → Экспорт логов. ZIP появится в Downloads.

**Q: Termux убивает процесс в фоне?**
Настройки → Приложения → Termux → Батарея → Без ограничений. В Termux: потяни уведомление → Acquire wakelock.

**Q: При установке termux-setup-storage не работает?**
Сначала выполни `apt update && apt full-upgrade -y`, потом `termux-setup-storage`.
